## ⚡ High-Priority Features (v1.5 - v2.0 Roadmap)

### 1. ☕ Keep Awake / Caffeine Mode (PowerToys Awake Style)
* **Description:** 1-click temporary sleep & display timeout inhibitor in the System Tray and Title Bar.
* **Key Capabilities:**
  * Preset durations: `30 mins`, `1 hour`, `2 hours`, `Indefinite`, or `Until active process finishes` (e.g. large downloads, video rendering, exports).
  * Implemented using native Win32 `SetThreadExecutionState` without altering permanent Windows Power Plan configurations.
  * System tray quick toggle with cup icon state change.
* **Reference:** [Microsoft PowerToys Awake](https://github.com/microsoft/PowerToys)

---

### 2. 🔋 Battery Conservation Mode / Charge Threshold Limiter (80% / 60%)
* **Description:** Native ACPI/WMI OEM battery charge limiting to prevent battery swelling and chemical wear when plugged in continuously.
* **Key Capabilities:**
  * 80% / 60% charge cap when AC adapter is connected.
  * Rapid charge / Express charge toggle.
  * Support for Lenovo (Vantage WMI / Legion Toolkit), ASUS (ATK/WMI G-Helper), Dell (Command WMI), HP, and Acer hardware interfaces.
* **Reference:** [LenovoLegionToolkit](https://github.com/BartoszCichecki/LenovoLegionToolkit) & [G-Helper](https://github.com/seerge/g-helper)

---

### 3. 🎯 Floating Hardware HUD & Compact In-Game Overlay
* **Description:** Minimalist, semi-transparent hardware vitals pill/overlay for desktop and gaming.
* **Key Capabilities:**
  * Real-time metrics: CPU/GPU temps, clock speeds, active Wattage draw (e.g., `18.5W`), battery drain rate, and active Power Mode.
  * Customizable position (Corner snap / draggable) and global toggle hotkey (e.g., `Ctrl + Shift + O`).
  * Low CPU overhead using non-polling Windows WMI / Performance Counters / LibreHardwareMonitor library.
* **Reference:** [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)

---

### 4. ⌨️ Global Hotkeys & Screen OSD Mode Flyout
* **Description:** Keyboard shortcuts to cycle power modes on the fly with a modern Windows 11 Fluent On-Screen Display (OSD) notification.
* **Key Capabilities:**
  * Configurable hotkey (e.g., `Win + Shift + P` or `Fn + Q` on supported laptops).
  * Centered translucent pop-up banner showing current mode transition: `🍃 Eco Mode` ➔ `⚡ Smart Mode` ➔ `🚀 Beast Mode` ➔ `🎮 Game Mode`.
  * Audio chirp feedback option on switch.

---

### 5. 🧹 Intelligent Standby List Cleaner (RAM Cache Auto-Purge / ISLC)
* **Description:** Eliminates Windows micro-stutters and memory bottlenecks during intensive gameplay.
* **Key Capabilities:**
  * Monitors Windows Standby Memory and Working Set.
  * Automatically purges the cached standby list when free memory drops below a configurable threshold (e.g., < 1024 MB) or when high-priority game executables launch.
* **Reference:** [Intelligent Standby List Cleaner (ISLC)](https://www.wagnardsoft.com/content/intelligent-standby-list-cleaner-v1028-released)

---

### 6. 🌙 Modern Standby Fix & Deep Sleep Auto-Hibernate
* **Description:** Prevents laptop battery drain and backpack overheating caused by Windows 11 Modern Standby (S0) bugs.
* **Key Capabilities:**
  * Auto-transition from Sleep to Hibernate after a user-defined period on battery (e.g. 15 or 30 minutes).
  * Auto-disables network connectivity during Modern Standby to eliminate battery drain while asleep.
  * Sleep battery drain diagnostics tool (analyzing Windows SleepStudy logs).

### 13. 🎮 Next-Gen Game Mode Engine (Deep System Optimization & Low-Latency Tuning)
* **Description:** What the **Game Mode Toggle** currently executes under the hood, plus advanced next-gen gaming optimizations.
* **What the Game Mode Toggle Currently Does:**
  * ⚡ **Ultimate Power Scheme Activation:** Triggers Windows `Ultimate Performance` / `High Performance` scheme, unlocking 100% CPU clock ceiling, disabling PCIe Link State Power Management, and eliminating CPU core parking.
  * 🖥️ **Max Refresh Rate Scaling:** Instantly switches display panel to highest native refresh rate (144Hz / 165Hz / 240Hz).
  * 🧹 **RAM Standby Cache Flush:** Purges Windows standby memory working set and cache to prevent frame drops and micro-stutters.
  * 🛑 **Dynamic Service Throttling:** Pauses non-essential background Windows services (Windows Update, Spooler, Diagnostics) during gaming and auto-restores them on Eco/Balanced.
  * 🚫 **Background App Killer / Suspend:** Terminates or suspends user-selected heavy background tasks (browsers, Discord, torrent clients, cloud syncs) with auto-restart upon game exit.
  * 🕹️ **Controller Navigation (Gopher360):** Enables full gamepad-to-mouse navigation for couch/living-room gaming.
  * 🎯 **Auto-Game Detection:** Listens for active game processes across Steam, Epic, Xbox Game Pass, GOG, and custom paths to automatically trigger optimizations.
* **Next-Gen Game Mode Roadmap Ideas:**
  * ⏱️ **0.5ms System Timer Resolution:** Temporarily call `NtSetTimerResolution` to force ultra-low input latency for competitive FPS titles.
  * 🧠 **CPU Core Pinning & Affinity (P-Core / AMD 3D V-Cache):** Bind game threads strictly to Performance cores on Intel 12th-14th Gen or cache-heavy CCD on AMD Ryzen 7000/9000X3D CPUs.
  * 🚀 **GPU Priority & HAGS Orchestration:** Set foreground game process scheduling priority to `High` / `Real-Time` with DirectX GPU preemption.
  * 🔕 **Windows Focus Assist & DND Auto-Trigger:** Automatically silence Windows 11 notifications, banners, and lock Windows Update driver installs during active gameplay.
  * 🎧 **Auto Audio Profile Switch:** Auto-apply competitive equalizer profiles (e.g. footsteps boost) or Dolby Atmos 3D audio when entering Game Mode.

### 14. 🪟 Winhance Engine Integration & Windows Optimization Suite (memstechtips/Winhance Blueprint)
* **Description:** Advanced system enhancement, transparency, unattended deployment, and persistent update protection inspired by [Winhance](https://github.com/memstechtips/Winhance) (`winhance.net`).
* **Key Capabilities & Synergies with AxePower:**
  * 🛡️ **Windows Update Driver Lock & Bloatware Re-Install Immunity Shield:**
    * **Driver Overwrite Protection:** Prevents Windows Update from silently overwriting custom OEM/NVIDIA/AMD GPU or audio drivers with generic Microsoft DCH drivers (`HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate` -> `ExcludeWUDriversInQualityUpdate = 1`).
    * **Anti-Bloat Re-provisioning:** Uses scheduled de-provisioning hooks and `DisableWindowsConsumerFeatures = 1` so that monthly Windows cumulative updates cannot resurrect deleted UWP bloatware (Clipchamp, Copilot, Edge web apps, sponsored tiles).
  * 🔍 **Interactive "Technical Inspector" & Registry Transparency Drawer (Zero Black Boxes):**
    * Expandable "Inspect Tweak Details" flyout for every toggle in System Optimizer, System Doctor, and Game Mode.
    * Displays exact Registry Key Paths, Property Names, Old vs New values, PowerShell equivalents, Service dependencies, and reboot requirements. Builds 100% trust with power users and system administrators.
  * ⚡ **Core Isolation & VBS (Virtualization-Based Security) Gaming Mode Switcher:**
    * 1-click toggle for Hypervisor-Enforced Code Integrity (HVCI) and Virtualization-Based Security (VBS) (`HKLM\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\HypervisorEnforcedCodeIntegrity` -> `Enabled = 0/1`).
    * Unlocks 5%–15% CPU frame rate gains and lower 1% low frame drops in esports titles (CS2, Valorant, Warzone) during Beast/Game Mode, with 1-click restore for maximum security in Smart/Eco Mode.
  * 🧼 **Clean Start Menu & Windows AI / Copilot Neutralizer:**
    * **1-Click Clean Start:** Unpins all default sponsored bloatware tiles and hides the Windows 11 "Recommended" section (`HideRecommendedSection = 1`).
    * **Disable Bing Web Search in Start:** Eliminates Start menu opening lag and web query latency by confining search strictly to local applications and files (`DisableSearchBoxSuggestions = 1`, `BingSearchEnabled = 0`).
    * **AI Background Agent Disablement:** Strips background NPU/CPU activity for Windows Recall and telemetry analysis (`DisableAIDataAnalysis = 1`, `TurnOffWindowsCopilot = 1`).
  * 📁 **Power-User File Explorer Studio & "Take Ownership" Integration:**
    * **Take Ownership Context Menu:** Adds a 1-click "Take Ownership" right-click action for stubborn permission-locked files, game directories, and mod folders.
    * **Explorer Quality-of-Life:** 1-click toggles for Show File Extensions (`HideFileExt = 0`), Show Hidden Files (`Hidden = 1`), and Compact View (`UseCompactMode = 1`).
    * **Restart Windows Explorer:** Instant 1-click Explorer restart button in Title Bar / Tray for fast shell refreshing.
  * 📜 **Visual Change Audit Timeline & Granular 1-Click Rollback:**
    * Upgrades AxePower's log viewer into an interactive **Audit Trail & Rollback Timeline**.
    * Chronologically logs every applied tweak with timestamp, user ID, exact before/after registry diffs, and provides an individual "Revert This Tweak" button backed by `%LocalAppData%\AxePower\tweak_rollback.json`.
  * 📦 **AxePower Fresh-Start Builder & Unattended Deployment (`autounattend.xml`):**
    * **Builder / Dry-Run Mode:** Configure AxePower settings, power plans, refresh rates, and debloat rules without immediately modifying the host machine.
    * **Unattended Answer File Generator:** Export configurations into a standardized `autounattend.xml` file or post-install bootstrap script for zero-touch clean Windows installations on new laptops and gaming rigs.
  * 🎨 **Dynamic Visual Effects (DWM) Performance Scaling:**
    * Dynamic desktop composition scaling tied to AxePower Power Modes:
      * **Eco Mode:** Automatically disables heavy drop shadows, window animations, and acrylic blurs to reduce GPU/DWM power draw and maximize battery life.
      * **Smart / Beast Mode:** Restores smooth Fluent animations and font smoothing (`FontSmoothing = 2`) for a crisp visual experience.
  * ⚙️ **Granular Windows Services Optimizer & Live State Inspector:**
    * Visual service controller with live state indicators (Running, Stopped, Disabled) and risk ratings for non-essential services (`SysMain`, `WSearch`, `DiagTrack`, `MapsBroker`, `Spooler`, `Xbox Services`).
* **Reference:** [Winhance (memstechtips/Winhance)](https://github.com/memstechtips/Winhance) & [winhance.net](https://winhance.net)
