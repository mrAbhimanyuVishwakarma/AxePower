# AxePower Feature Ideas & Roadmap

1. System Stats & Hardware Telemetry (Steam/MSI style)
   - Real-time CPU/GPU temperatures, clock speeds, utilization, power draw (Watts), and VRAM.
   - Live battery discharge rate in Watts (e.g., -14.5W drain) and estimated runtime at current load.
   - In-app telemetry cards and optional compact floating desktop/gaming HUD overlay.
   - References: LibreHardwareMonitor / MSI Afterburner

2. Keep Awake / Caffeine Mode (from Microsoft PowerToys Awake)
   - One-click temporary sleep prevention toggle in System Tray or Title Bar (30m / 1h / Infinite / Until process ends).
   - Uses SetThreadExecutionState Win32 API without modifying permanent Windows power plans.
   - Reference: https://github.com/microsoft/PowerToys.git

3. Phone / Android Control (Integrated Scrcpy)
   - Ultra-low latency Android screen mirroring & full keyboard/mouse control via USB & Wi-Fi.
   - Reference: https://github.com/Genymobile/scrcpy.git

4. Controller to Mouse/Keyboard Navigation (Gopher360 Companion)
   - Control Windows desktop using an Xbox / PlayStation / generic controller when gaming on TV/couch.
   - Reference: https://github.com/wishIwasabear/Gopher360.git

5. Battery Conservation Mode / Charge Threshold Limit (80% / 60%)
   - Native ACPI/WMI hardware charge limiting to extend laptop battery lifespan (Lenovo / ASUS / OEM support).
   - Reference: https://github.com/BartoszCichecki/LenovoLegionToolkit.git

6. CPU Power Limits (TDP / Wattage) & dGPU Eco Mode
   - Custom Wattage/TDP clamps per power profile (e.g., 15W Eco limit for maximum battery, 65W+ Beast mode).
   - Dedicated GPU Eco switch (completely power down dGPU on battery power).
   - Reference: https://github.com/seerge/g-helper.git

7. Dynamic Display Refresh Rate & Global Hotkeys
   - Smooth 60Hz <-> 144Hz/165Hz/240Hz auto-switch on AC plug/unplug via ChangeDisplaySettingsEx.
   - Global hotkey support (e.g., Win + Shift + P) to cycle through Eco -> Smart -> Beast -> Game modes.
   - Reference: https://github.com/BartoszCichecki/LenovoLegionToolkit.git & PowerToys

8. Smart AI / Heuristic Power Advisor
   - Local heuristics to detect high background battery drains and suggest one-click optimizations.
   - Auto game genre profiling.
   - Reference: https://github.com/microsoft/generative-ai-for-beginners.git

9. System Optimizer, Debloat & Maintenance Hub (from Chris Titus WinUtil)
   - Dynamic Service Optimizer: Auto-pause heavy services (SysMain, Search Indexing, Telemetry) in Eco Mode to save battery & CPU cycles.
   - Privacy & Telemetry Debloat: Disable diagnostic telemetry, Bing search in Start Menu, Cortana/Copilot overheads.
   - Gamer Tweaks: Disable GameDVR background capture stutters, disable mouse acceleration for 1:1 input.
   - Windows Update & Reboot Shield: Security updates only policy, prevent surprise reboots mid-game.
   - System Doctor & Maintenance: SFC/DISM health repairs, junk & DirectX shader cache cleaner, network/DNS flush.
   - Low-Latency DNS Switcher: 1-click switch & ping benchmark (Cloudflare 1.1.1.1, Quad9, Google DNS).
   - WinGet Software & Runtimes Hub: 1-click batch installer for VC++ runtimes, DirectX, gaming launchers, and 1-click app updates.
   - Reference & Blueprint: winutilreference.md & https://github.com/ChrisTitusTech/winutil.git

10. Phone Control (All-in-One Mobile Suite)
   - 📂 LAN Drop (Local Wi-Fi Quick File Transfer & Clipboard Drop)
   - 📱 Android Screen Mirroring & Low-Latency Control (scrcpy)
   - ⚡ Remote PC Companion (Mobile web widget for battery stats, media playback & remote PC lock)
