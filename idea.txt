# 🚀 AxePower - Future Feature Ideas & Product Roadmap 💡

---

## ⚡ High-Priority Features (v1.5 - v2.0 Roadmap)

### 1. ☕ Keep Awake / Caffeine Mode (PowerToys Awake Style)
* **Description:** 1-click temporary sleep & display timeout inhibitor in the System Tray and Title Bar.
* **Key Capabilities:**
  * Preset durations: `30 mins`, `1 hour`, `2 hours`, `Indefinite`, or `Until active process finishes` (e.g. large downloads, video rendering, exports).
  * Implemented using native Win32 `SetThreadExecutionState` without altering permanent Windows Power Plan configurations.
  * System tray quick toggle with cup icon state change.
* **Reference:** [Microsoft PowerToys Awake](https://github.com/microsoft/PowerToys)

---

### 2. 🔋 Battery Conservation Mode / Charge Threshold Limiter (80% / 60%)
* **Description:** Native ACPI/WMI OEM battery charge limiting to prevent battery swelling and chemical wear when plugged in continuously.
* **Key Capabilities:**
  * 80% / 60% charge cap when AC adapter is connected.
  * Rapid charge / Express charge toggle.
  * Support for Lenovo (Vantage WMI / Legion Toolkit), ASUS (ATK/WMI G-Helper), Dell (Command WMI), HP, and Acer hardware interfaces.
* **Reference:** [LenovoLegionToolkit](https://github.com/BartoszCichecki/LenovoLegionToolkit) & [G-Helper](https://github.com/seerge/g-helper)

---

### 3. 🎯 Floating Hardware HUD & Compact In-Game Overlay
* **Description:** Minimalist, semi-transparent hardware vitals pill/overlay for desktop and gaming.
* **Key Capabilities:**
  * Real-time metrics: CPU/GPU temps, clock speeds, active Wattage draw (e.g., `18.5W`), battery drain rate, and active Power Mode.
  * Customizable position (Corner snap / draggable) and global toggle hotkey (e.g., `Ctrl + Shift + O`).
  * Low CPU overhead using non-polling Windows WMI / Performance Counters / LibreHardwareMonitor library.
* **Reference:** [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)

---

### 4. ⌨️ Global Hotkeys & Screen OSD Mode Flyout
* **Description:** Keyboard shortcuts to cycle power modes on the fly with a modern Windows 11 Fluent On-Screen Display (OSD) notification.
* **Key Capabilities:**
  * Configurable hotkey (e.g., `Win + Shift + P` or `Fn + Q` on supported laptops).
  * Centered translucent pop-up banner showing current mode transition: `🍃 Eco Mode` ➔ `⚡ Smart Mode` ➔ `🚀 Beast Mode` ➔ `🎮 Game Mode`.
  * Audio chirp feedback option on switch.

---

### 5. 🧹 Intelligent Standby List Cleaner (RAM Cache Auto-Purge / ISLC)
* **Description:** Eliminates Windows micro-stutters and memory bottlenecks during intensive gameplay.
* **Key Capabilities:**
  * Monitors Windows Standby Memory and Working Set.
  * Automatically purges the cached standby list when free memory drops below a configurable threshold (e.g., < 1024 MB) or when high-priority game executables launch.
* **Reference:** [Intelligent Standby List Cleaner (ISLC)](https://www.wagnardsoft.com/content/intelligent-standby-list-cleaner-v1028-released)

---

### 6. 🌙 Modern Standby Fix & Deep Sleep Auto-Hibernate
* **Description:** Prevents laptop battery drain and backpack overheating caused by Windows 11 Modern Standby (S0) bugs.
* **Key Capabilities:**
  * Auto-transition from Sleep to Hibernate after a user-defined period on battery (e.g. 15 or 30 minutes).
  * Auto-disables network connectivity during Modern Standby to eliminate battery drain while asleep.
  * Sleep battery drain diagnostics tool (analyzing Windows SleepStudy logs).

---

### 7. 🔊 Quick Per-App Audio Mixer & Output Device Switcher
* **Description:** Streamlined volume mixer and audio output switcher integrated into AxePower Tray / Dashboard.
* **Key Capabilities:**
  * 1-click switch between Headset, Speakers, Display Audio, and Bluetooth.
  * Independent volume sliders for foreground game vs Discord / Spotify.
  * Auto-switch audio profile to surround sound / spatial audio in Game Mode.

---

### 8. 📱 Remote Phone Web Dashboard & Quick PC Actions
* **Description:** Lightweight local web companion running on local port (no app installation needed on phone).
* **Key Capabilities:**
  * Open web UI via QR code scan on mobile browser.
  * View live laptop battery percentage, temperature, and AC status from bed/couch.
  * Remote PC quick actions: Lock PC, Sleep, Switch Power Mode, Adjust Volume, or Media Play/Pause.

---

### 9. 📈 Battery & Gaming Usage Analytics (Weekly Insights)
* **Description:** Local telemetry history and efficiency reporting.
* **Key Capabilities:**
  * Weekly battery runtime comparisons, total hours gamed, and estimated energy saved in Eco Mode.
  * Battery health degradation curve (Full Charge Capacity vs Design Capacity over months).
  * Exportable battery health summary report (HTML / PDF).

---

### 10. 🕹️ Lossless Scaling & Game Optimizers Companion
* **Description:** Quick profile launcher and config integration with modern gaming scaling utilities.
* **Key Capabilities:**
  * Integration with [Lossless Scaling](https://store.steampowered.com/app/993090/Lossless_Scaling/) (LSFG Frame Generation / AMD FSR / Integer Scaling).
  * Pre-configured resolution scaling profiles for battery-powered gaming.
