Privacy Policy & Architecture

Synced with AxePower Desktop & Mobile v1.4 • Updated 2026

1. Privacy & Data Security (100% Local)

AxePower is engineered with absolute privacy at its core. The application and website do not collect, record, track, sell, or transmit any personal information, telemetry, device identifiers, or usage statistics to external servers. All power configurations, profile automations, and hardware adjustments execute 100% locally on your machine.

2. Hardware Telemetry & Sensor Processing

All hardware telemetry (CPU/GPU utilization, clock speeds, RAM usage, battery discharge rates, temperature readings, and fan RPMs) is measured in real-time in local memory via native Windows Win32 APIs and hardware registers. No system state data ever leaves your computer.

3. Android Companion & Local Network Sync

The AxePower Android Companion connects directly to your PC via your local area network (Wi-Fi) or direct USB connection using end-to-end local sockets. Zero communication is routed through cloud relays or external servers.

4. GitHub Release Updates

AxePower and AxePower.com communicate with the public GitHub REST API (api.github.com/repos/mrAbhimanyuVishwakarma/AxePower_Download/releases/latest) exclusively to detect and download verified installer binaries.

5. Open Source Credits & Acknowledgements

AxePower coordinates with exceptional open-source utilities:

  • Gopher360: Controller-to-mouse navigation integration by Tylemagne.
  • scrcpy: Android screen mirroring and control by Genymobile.
  • Win11Debloat: Windows debloating scripts created by Raphire.
  • MSI Afterburner & RTSS: Hardware statistics and GPU overlay engine by MSI and Alexey Nicolaychuk (Guru3D).
  • Windows Package Manager (winget) & USOClient: Software updates by Microsoft.
  • Hardcodet.Wpf.TaskbarNotification: Windows tray integration by Philipp Sumi.
  • CommunityToolkit.Mvvm: MVVM architecture by the .NET Community & Microsoft.
