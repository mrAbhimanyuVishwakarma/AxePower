What's New in Version 2.1.0

Released September 30, 2026

Full Release Notes ↗
🧰 Unified System Care

Optimizer and Doctor now share a collapsible workspace for recommended tweaks, Windows health repairs, junk cleanup, DNS tools, restore points, and live command output.

🛡️ Windows Update Controls

Apply the recommended security-only update policy, prevent forced reboots while signed in, repair the Windows Update cache and services, and create a restore point before changes.

🧭 Responsive Software Hub

Browse runtimes, gaming, hardware tuning, and utilities from a collapsible category rail. Actions stay on the right when space permits and move below details only in compact layouts.

🗂️ Table-Based Uninstaller

Dedicated Win32 and Windows Apps views now use a full-width sortable table with application type, size, version, install date, company, batch selection, and Select All for leftovers.

🔔 Working Notifications

Desktop notifications, automatic power-mode notices, and the low-battery alert chime now follow persistent Settings toggles and runtime events.

🎮 Clear Game Mode States

Only the applied mode stays active, while a manually selected Eco, Smart, or Beast card previews its glow before Apply so the next choice is always clear.

🧹 Cleaner Navigation

Maintenance now contains Windows Update, System Care, Uninstaller, and Debloat; Utilities keeps Terminal and Tools close at hand.

🚀 Reliable In-App Updates

Background and manual updates share one verified download, tolerate slow GitHub responses, show clear progress and failures, and launch only a complete Windows installer.
