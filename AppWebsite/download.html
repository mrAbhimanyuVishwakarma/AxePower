What's New in Version 1.9.0

Latest update released September 2026

Full Release Notes ↗
🎵 Integrated Music Player & Media Hub

In-app audio playback engine with local library support, YouTube audio streaming, Spotify controller, and a sleek Header Player matching the dashboard design that automatically follows Windows audio device switching.

🖥️ ShareScreen & GameStream

Stream your PC screen or gaming session directly to friends via a local web link. Viewers connect in any browser with low latency and audio with zero software installation needed on their end.

🗑️ Next-Gen Uninstaller Pro

Overhauled leftover scanner featuring confidence scoring, deep registry/filesystem probes, safety backups, and a dedicated Broken Entry Executor to clean corrupted Windows uninstall records.

🔋 Battery Diagnostics & UI Polish

Streamlined battery history card layout with responsive sparklines and cleaner metrics, persistent sidebar group states, and elimination of binding errors during dashboard startup.

🖥️ Built-In Terminal (CMD & PowerShell)

A real interactive shell inside AxePower where Software Hub installs and System Doctor diagnostics stream their live progress, featuring an instant Stop button to cancel tasks.

🌡️ Driver-Free Temperatures & Admin Mode

Hardware temperature monitoring that works even with Windows 11 Memory Integrity turned on, alongside Run as administrator setting with clean boot elevation and no UAC prompts.
