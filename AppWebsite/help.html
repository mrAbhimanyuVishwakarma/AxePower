Terminal, Administrator Rights & Temperatures Built into AxePower v1.8.0

The built-in CMD / PowerShell console, how AxePower elevates without nagging you, and why its temperature readings work where other tools show nothing.

🖥️ Using the Built-In Terminal

Open Terminal under Maintenance in the sidebar. It runs a real, persistent shell — not a log window — and it is also where every command AxePower itself runs reports to, so nothing happens behind a spinner any more.

  • 1 Switch between PowerShell and Command Prompt at the top of the page.
  • 2 Start an install from the Software Hub or a repair from System Doctor — AxePower jumps here and streams the live output.
  • 3 Press Stop to cancel whatever is running, including a long diagnostic started from another page.
  • ✓ The shell inherits AxePower's privilege level — run the app as administrator and the terminal is elevated too.

🛡️ Administrator Rights Without the UAC Nagging

Sensor reads, system tweaks, debloat actions and the terminal all need administrator rights. AxePower asks for them in a way you can still say no to.

  • ✓ Settings → Run as administrator is on by default. Turn it off and AxePower runs as a standard user — most tools do not let you.
  • ✓ Already running unelevated? Use Relaunch with Admin in the title bar, or Restart as administrator now in Settings. The button disappears once you are elevated.
  • ✓ At boot there is no UAC prompt at all — the logon task is registered at HighestAvailable instead of the app demanding elevation in its manifest.
  • ✓ Dismissing a UAC prompt is safe — AxePower carries on as a standard user rather than asking again in a loop.

🌡️ Why the Temperatures Actually Work

Most monitoring tools read CPU temperature through a kernel driver (WinRing0). On current Windows 11 that driver is on Microsoft's vulnerable-driver blocklist, so with Memory Integrity enabled — the default on new machines — it silently fails and the readings come back empty. AxePower tries three sources in order:

  • 1 Lenovo firmware (ACPI-WMI) — the same interface Lenovo Vantage and Legion Toolkit use. No kernel driver, so Memory Integrity does not affect it. Needs administrator rights.
  • 2 MSI Afterburner — if it is running, AxePower reads the sensor table it already publishes. No driver of our own, no elevation needed, and the numbers match what Afterburner shows.
  • 3 LibreHardwareMonitor — the traditional MSR route, used when the first two are unavailable.
  • ✓ If only the ACPI chassis sensor can be read, AxePower says so rather than passing an ambient number off as your CPU die temperature.

💾 Create a System Restore Point First

Before debloating, tweaking or bulk-installing, take a checkpoint you can roll back to.

  • 1 Make sure AxePower is elevated — creating a restore point requires administrator rights.
  • 2 Open the Software Hub and click Create Restore Point. Progress streams to the Terminal page.
  • ✓ AxePower enables System Restore on the system drive and removes the once-per-24-hours throttle first, so the checkpoint is genuinely written instead of silently skipped.
  • ✓ Verify any time under Windows → System Protection → System Restore.

Controller Navigation Powered by Gopher360 (wishIwasabear)

Control your entire Windows desktop, browser, and media with an Xbox / XInput gamepad.

🕹️ Gamepad Button Mapping

📋 Step-by-Step Setup

  • 1 Connect your Xbox Series X/S, Xbox One, Xbox 360, or any standard XInput-compatible gamepad via Bluetooth or USB cable.
  • 2 Turn ON the 'Controller Navigation' toggle switch on the AxePower Dashboard.
  • 3 Use the Left Thumbstick to glide the mouse pointer and A button to click anywhere on screen.
  • 4 Whenever you launch a full-screen game, press Back + Start together to disable desktop navigation so the game receives native controller inputs.
💡 Pro Tip: Controller Navigation runs invisibly in your system tray. You can leave the toggle ON and use the Back + Start shortcut anytime to switch between mouse mode and gameplay mode without opening AxePower.

Phone Control & LAN Drop Powered by scrcpy & LAN-DropSpot

Ultra-fast local file sharing, live clipboard sync, and low-latency Android screen mirroring.

🌐 LAN Drop (Zero-Install File Sharing)

  • 1 Ensure your PC and phone are connected to the same Wi-Fi network.
  • 2 In AxePower, open Phone Control > LAN Drop and click Start Server.
  • 3 Point your phone camera at the QR code displayed on screen to open the transfer portal in your browser.
  • 4 Drag and drop photos, documents, videos, or send text snippets. Files are transferred at full local Wi-Fi gigabit speeds without using cloud or mobile data.

🪞 Android Screen Mirroring (scrcpy)

  • 1 Enable Developer Options and USB Debugging on your Android phone.
  • 2 Connect phone via USB cable and tap Allow Always on the RSA fingerprint prompt.
  • 3 Click Mirror Screen in AxePower. Use keyboard and mouse for full phone control.
  • 4 Shortcuts: Press Ctrl + F for fullscreen, Ctrl + H for Home, and drag APKs onto the window to install.

MSI Afterburner & RivaTuner Powered by Guru3D / MSI

Real-time in-game FPS counter, GPU temperature tracking, and custom cooling fan profiles.

📊 Setting Up In-Game Telemetry

  • 1 Click MSI Afterburner in the AxePower sidebar to launch it in background monitoring mode.
  • 2 Open Afterburner Settings > Monitoring tab.
  • 3 Check the metrics you want (Framerate, GPU Temperature, GPU Usage, Memory Clock) and check Show in On-Screen Display.
  • 4 Launch your game — your real-time stats will appear in the top corner.

❄️ Custom Fan Curve & Tuning

  • 1 In Afterburner Settings, navigate to the Fan tab and enable user-defined software automatic fan control.
  • 2 Adjust curve points to ramp fan speeds higher when GPU temperature exceeds 65°C.
  • 3 Click Apply and save to profile slot 1 for persistent thermal safety.

Smart Battery & Dynamic Power Modes AxePower Intelligent Power Engine

Optimize power draw, monitor battery wear, and protect lifespan with charging thresholds.

⚡ Power Profiles Explained

  • 🌱 Eco Mode: Reduces CPU clock states and background activity to maximize battery endurance during travel or quiet work.
  • ⚡ Smart Mode: Dynamically scales performance between productivity tasks and moderate gaming.
  • 🔥 Beast Mode: Unlocks maximum CPU/GPU power limits and sets system power plan to Ultimate Performance.

  • ✓ Enable Battery Conservation Mode on the Battery page.
  • ✓ Automatically caps charging at 75-80% to double long-term battery lifespan.

Task Manager Telemetry & 24h Battery History Built into AxePower

Real-time CPU, GPU, RAM, and Internet performance tracking with zero-baseline live sparklines.

📈 2x2 Performance Grid Metrics

  • CPU Processor Load & Clock: High-precision kernel timing measuring real-time CPU utilization percentage and live base/boost GHz.
  • GPU WDDM 3D & Thermals: Direct DirectX/WDDM graphics engine load and discrete GPU temperature monitoring (e.g. RTX 4060).
  • RAM Memory Allocation: Live physical RAM consumption in gigabytes (Used / Total GB) and percentage utilization.
  • NET Network Bandwidth: Dynamic upload and download rates (Kbps, Mbps, MB/s) across active Wi-Fi and Ethernet adapters.

🔋 24-Hour Continuous Battery Timeline

The 24-hour battery trend graph displays a rolling curve of your PC's power state over the past day:

  • 1 Timeline Axis: Markers indicate battery states at 24h ago, 12h ago, and Now.
  • 2 Charge Tracking: Real-time detection of charging, discharging, and AC adapter connection status.
  • 3 Zero Overhead: Sparklines and curves are drawn using hardware-accelerated WPF StreamGeometry with sub-millisecond redraw costs.
