## 🌟 Major Milestones (v2.0 - v2.1.0)

### ✅ 🎵 Compact Music Player & Universal Media Engine
* **Implemented In:** `AxePower.Core/Services/Music/`, `AxePower.App/Views/Music/`, `HeaderPlayer.xaml`, `AmbientModeOverlay.xaml`
* **Features Delivered:**
  * **Audiophile-Grade Playback Engine:** Low-overhead audio streaming engine with WASAPI support, volume control, track seekbar, and queue management.
  * **Universal Windows SMTC Integration:** Hooks into `GlobalSystemMediaTransportControlsSessionManager` to detect, display metadata for, and control media playing on Windows (Spotify, Apple Music, YouTube in browsers, VLC, Foobar2000).
  * **Header Mini Player & Ambient Visualizer:** Compact player embedded in the app header and ambient mode overlay with live audio visualizer bars, synchronized lyrics, and seek control.
  * **Smart Game Mode Automation:** Background music pause / ducking options during gaming or voice communications.
  * **Remote Integration:** Web remote playback controls streamed through local LAN Drop companion dashboard (`http://<local-ip>:5050`).

## 🏛️ Core Features Archive (v1.0 - v1.4)

* ✅ **Smart Power Modes (Eco, Smart, Beast, Game Mode):** Full dynamic AC/DC power plan switching.
* ✅ **Intelligent Auto-Switch Engine:** Dynamic rules (Plugged In: Smart/Beast, Unplugged: Eco, Battery <30%: Eco).
* ✅ **Display Refresh Rate Auto-Scaling:** 60Hz on Battery &harr; 144Hz/165Hz/240Hz on AC via `ChangeDisplaySettingsEx`.
* ✅ **Controller Navigation (Gopher360):** Full gamepad-to-mouse & keyboard living-room navigation.
* ✅ **Phone Control Suite:**
  * 📱 **scrcpy:** Low-latency Android screen mirroring, stay-awake, and APK installer.
  * 🖥️ **SpaceDesk:** Wireless phone/tablet secondary display integration.
  * 📂 **LAN Drop:** Instant local Wi-Fi file sharing & clipboard synchronization.
* ✅ **Software Hub:** 1-click installer and launcher for 25+ top storefronts, monitors, and runtimes.
* ✅ **Modern Dark Fluent WPF UI:** Responsive card layout with collapsible sidebar navigation and Segoe UI typography.
* ✅ **Inno Setup 6 Packaging:** Clean upgrade engine with desktop shortcuts and uninstaller registration.
