# AxePower UI Design

* **Premium Windows 11 Fluent-inspired Visual Direction**: Aim for a modern, refined look.
* **AxePower Branding**: Maintain a dark navy visual identity.
* **Layout Structure**: Use left navigation and a responsive dashboard.
* **Themes**: Support dark, light, system, and contrast themes.
* **Semantic Resources**: Use semantic brush names (e.g., `WindowBackgroundBrush`, `AccentBrush`) instead of hard-coded colors.
* **Typography & Spacing**: Use `Segoe UI Variable` (fallback `Segoe UI`) and consistent spacing/corner radii.
* **Mode-Card Behaviour**: Ensure cards clearly indicate Eco, Smart, or Beast modes with distinct visual accents.
* **States**: Implement visible loading, empty, disabled, success, warning, and error states.
* **Accessibility**: Ensure logical tab order, keyboard focus, accessible names, contrast compatibility, and screen reader support.
* **Responsive Layouts**: Support High-DPI screens and dynamic sizing (125%, 150%, 200%). Use Grids, WrapPanels, and ScrollViewers appropriately.
* **Design Constraints**:
  * No fake metrics or unsupported claims.
  * No large solid saturated card backgrounds.
  * No absolute screenshot-only positioning.
  * No hidden or clipped primary buttons.
  * The supplied design reference is visual guidance, not a source for fake functionality.
