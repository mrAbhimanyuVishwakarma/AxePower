# AxePower v2.1.5 — Windows Update & Gaming Tools

## What's new

- **Windows Update overview** groups Windows, WinGet apps, optional drivers, and BIOS and UEFI firmware into collapsible sections. The graphics cards move below the scan controls in narrow windows.
- **WinGet review and progress** lets you confirm selected upgrades or run a separate bulk update. Including apps with unknown installed versions is optional. Results show failures and restart requirements when available.
- **Graphics software** opens the matching NVIDIA, Intel, or AMD vendor app for the hardware AxePower detects. NVIDIA also has a Control Panel shortcut and a driver version list.
- **Gaming Runtimes & Tools** adds Veyra for NVIDIA and AMD with SHA-256 verification, plus links to DLSS 5 Manager and PushFPS. Dashboard → What's New opens with Veyra, DLSS 5 Manager, and DLSS 5 Swapper.
- **Navigation and shortcuts** remember your sidebar groups and tray choices. Open Game Mode from the Dashboard or launch BCUninstaller from Uninstaller and Tools.
- **Second Monitor** offers Android and iOS viewer downloads and explains the iOS Local Network permission. The discontinued HTML5 viewer shortcut and the retired Friends and Share Screen rooms have been removed.

## Install or update

- Download `AxePower-v2.1.5-Setup.exe` from the assets below. It supports an in-place upgrade.
- Existing users can check through **Settings → Updates & Maintenance → Check for updates**. If your installed build cannot verify the update, use Setup from this release.
- Windows 11 x64 is recommended. A serviced Windows 10 x64 edition compatible with .NET 10 is required for Windows 10. Setup checks the x64 .NET 10 Desktop Runtime and installs it when needed. For offline setup, install the [x64 .NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) before running Setup.
- Setup needs administrator approval. You can run AxePower as a standard user after installation.
